# Simple Registration Form with Real-Time Validation

A beginner-friendly, responsive user registration interface built using **HTML table layout**, **CSS card styling**, and **Vanilla JavaScript**. 

This project demonstrates clean structural formatting alongside real-time client-side form validation.

## ✨ Features

- **Table-Driven Grid Layout:** Uses an HTML structural table to perfectly stack labels, inputs, and errors.
- **Card UI Design:** Features a modern, floating white card design with subtle drop shadows matching professional UI screens.
- **Real-Time Input Validation:** Evaluates data instantly on every keystroke (`oninput` event listeners).
- **Dynamic Button Control:** The `Submit` button stays disabled (grayed out) until all input fields satisfy the rules.

## 🛠️ Validation Rules Implemented

- **Name:** Cannot be left blank or empty.
- **Email:** Scans the text input to ensure it contains standard components (`@` and `.`).
- **Password:** Mandates a minimum security length of at least 6 characters.

## 🚀 Technologies Used

- **HTML5** - Page structure and table layout
- **CSS3** - Card presentation, alignment, and button states
- **JavaScript (ES6)** - Validation logic and state handling

## 📄 How to Run Locally

1. Clone or download this repository to your local computer.
2. Open the `index.html` file in any standard web browser (Chrome, Safari, Edge, Firefox).
3. Type in the input fields to see the validation errors appear and disappear in real time!
